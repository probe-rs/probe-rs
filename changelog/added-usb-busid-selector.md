Select the ST-Link or FTDI probe plugged into a USB port with `--probe usb-busid://BUS-PORT.PORT`, as in `usb-busid://1-1.2`, on the command line or from an RPC client. `probe-rs list` shows the port of these probes. Configuration files cannot select a probe by port: the probe table and the access lists of `probe-rs serve` reject `usb-busid://`.
