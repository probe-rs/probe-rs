Added `reset_line_connected` and driver settings to the `probes` table of the configuration file. The CH347 reset pin can be configured to TRST or a GPIO. A reset pin on TRST forces SWD, because JTAG drives TRST. `probe-rs reset --method pin|core` overrides `reset_line_connected`. If the setting is false, probe-rs does not assert the reset line: `pin`, connect under reset and target sequences that need a pin reset fail.
