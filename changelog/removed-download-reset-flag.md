The `--reset` flag is removed from `probe-rs download`, `probe-rs run`, `probe-rs profile` and `cargo-flash`. A shared option set gave the flag to all four commands, but only `probe-rs download` used it. In `probe-rs profile` the name was the same as the name of a different flag, and clap stopped every debug build of `probe-rs` with an error at start. To start the firmware after a download, use `probe-rs download --start`.
